# 5-Axis Robotic Arm

A 5-Axis Robotic Arm developed using Arduino UNO and servo motors. The system features a Teach Pendant that allows users to manually control the arm, record motion sequences, and replay them automatically. The teach-and-repeat functionality enables the robot to perform repetitive tasks accurately without complex programming, making it suitable for robotics education, research, and automation projects.

## Overview

This project demonstrates the design and implementation of a low-cost robotic arm capable of performing basic object manipulation tasks. The arm provides five degrees of freedom, allowing movement in multiple axes for improved flexibility and control.

The Teach Pendant serves as a user-friendly interface for controlling the arm's joints. Motion sequences can be stored and replayed, simulating the programming methods used in industrial robotic systems.

## Features

- 5 Degrees of Freedom (5-DOF)
- Arduino UNO based control system
- Teach Pendant for manual operation
- Motion recording and playback
- Teach-and-Repeat functionality
- Servo motor control using PWM signals
- Emergency Stop feature
- Low-cost and educational design
- Suitable for pick-and-place operations

## Working Principle

The robotic arm is manually controlled using potentiometers on the Teach Pendant. The desired positions of each joint are recorded and stored in memory. Once a sequence is saved, the robotic arm can automatically replay the same movements in the recorded order. This allows repetitive tasks to be performed consistently and accurately.
